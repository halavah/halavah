# 旧站依赖归档

`legacy-node-dependencies.zip` 保存旧 Hexo 根目录和 Chic 主题的原始 npm 清单，以及 npm、Yarn 锁文件。当前网站由根目录 `docs/` 发布，旧站依赖不参与构建或部署。

恢复时，把整个旧站备份复制到独立的离线目录。进入该目录后运行 `unzip -n legacy-node-dependencies.zip`，解压会还原根目录及 `themes/Chic/` 内的文件。校验压缩包前可用 `shasum -a 256 legacy-node-dependencies.zip`，将结果与本目录 `SHA256.json` 中的对应值比对。原文件校验值如下。

| 路径 | SHA-256 |
|---|---|
| `package.json` | `1ee3807de46725010f45708b88225d3cacf79755ba266f8b8840a34ecc3f71ce` |
| `package-lock.json` | `33a3e70169eb83ba1f8641b0ec83e03df275fc9e087eede5bd9f49f80baf4648` |
| `yarn.lock` | `b950b597461f3c1c96d6a066f8a965727a468f9b89a20f6cb785a6548625db0c` |
| `themes/Chic/package.json` | `f72cffa45cd329771fff8a7542a6c73166908077d3f6dc4e2e6b01cc4797281f` |

归档保留原始依赖版本，其中仍有已知漏洞。恢复旧站用于运行前应单独完成升级和验证。
